# Disputr professional UI pack

## Upload to GitHub Pages
1. Upload every file in this folder, including the `assets` folder.
2. Keep `index.html` in the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Do not delete `assets/styles.css`; every page links to it.

- Travel: company selector → issue selector → complaint builder → evidence checklist → timeline

## Important
This is a polished static front-end. Buttons/forms that save data, take payment, upload files or send messages remain demonstrations until connected to a secure backend and payment provider. Review all legal, privacy, subscription and marketing copy before commercial launch.
